# Agent guidance

Agents working in this repository must read the maintainer's canonical private instructions before replying or changing files. Private conversation conventions apply to chat and task status, while all repository content and public writing use ordinary professional English. Never copy private conversation wording into source, comments, documentation, commit messages, issues, releases, or the website. Preserve exact technical identifiers.

The live lightning signal is safety relevant. Invalid, stale, incomplete, or non-georeferenced data must never produce a green state. Keep observed lightning distinct from forecast thunderstorms and from a user report of hearing thunder. Use the real built surfaces for verification and genuine captures.
