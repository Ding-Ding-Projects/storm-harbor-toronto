# Handoff

The core map and signal source is in progress. The source uses ECCC GeoMet WMS for visualization and WCS GeoTIFF for numeric proximity analysis, plus Open-Meteo for forecast thunderstorm codes. The app defaults to Toronto and lets users move the map pin or request device location.

Build, install, live-source, visual, publication, and package verification must be recorded here before any release is called complete. Keep the roadmap checkboxes aligned with that evidence.
